# Which patch each changed src/engine/ file belongs to. tools/refresh_patches.sh reads this.
#
#   [patch-name.patch] description (becomes the patch's first line)
#   glob                (path relative to src/engine/, * matches within a folder, ** across folders)
#
# The first matching glob wins. A changed file that matches nothing stops the refresh: add it here first.
# Patches apply in file name order. Ranges:
#   0001-0009  build and launcher plumbing, any game
#   0010-0099  fixes to SurrealEngine bugs that aren't specific to one game
#   0100-0199  KnowWonder engine (calls into src/knowwonder/, gated by IsKnowWonder(); HP1-only bits by IsHarryPotter1())
#   0200-0299  free for game-specific additions (HP2)
# Patches split by file, so a file has exactly one owner.
